## 功能

- 🎲 **十源加权轮换**：青春 / 甜妹（权重高，池大且新）、热点 / 热舞 / 街拍、古装 / COS、精选 / 合集 / 站长
- 🚫 **不重样**：本地记录最近 1500 条看过的直链，解析出重复自动换源重取（最多 5 次）
- ⚡ **两段式秒开**：切换后立即解析下一条直链（零带宽成本），当前视频缓冲达标后才拉下一条——预载永不抢带宽；按近期加载中位数自适应预载阈值与超时兜底
- 🛡️ **多重容错**：服务端解析先验活（死链直接换）；坏源自学习剔除；自适应超时踢出；解析失败重试换源
- 🎚 **多候选择优（更高清）**：服务端并发拉取多个分类，探测每条视频的真实分辨率/时长/码率（解析 MP4 头部），挑码率最高的一条返回
- 📈 **码率自学习**：按实测码率给各源加权，总能推出更清晰的源；信息栏显示实时分辨率 + 码率
- 🎮 **画质档位**：流畅 / 均衡 / 高清 / 极致——档位越高并发候选越多、码率门槛越高
- 🛡️ **帧率守护**：实测持续掉帧自动精简背景装饰，保播放流畅
- 📣 **抖音近期源（可选）**：到 [istero.com](https://api.istero.com) 免费注册拿 Token，填入账号面板
- ↩️ **回看**：回到上一条，保留播放位置瞬间恢复
- ❤️ **收藏**：查看原始信息——博主 ID、发布时间、原始页面链接、视频直链、时长分辨率
- 🕘 **历史记录**：自动记录最近 100 条，可清空
- 👤 **本地账号**：ID + 密码（SHA-256 加盐哈希），收藏 / 历史 / 点赞按账号分开
- ⬇️ **下载**：前端直接拉流保存（无水印）

**快捷键**：`↑` 下一条 · `↓` 回看 · `空格` 暂停 · `R` 随机 · `M` 静音 · `L` 点赞 · `F` 收藏 · `D` 下载 · `H` 记录 · 双击画面点赞

## 部署

支持 **docker run**、**docker compose**、**GitHub Pages（直连模式）**、**本地常驻** 四种方式，完整命令与环境变量见 **[DEPLOY.md](DEPLOY.md)**。

```bash
# docker run（源码构建）
git clone https://github.com/dll315/beauty-reels-pro.git && cd beauty-reels-pro
docker build -t girl-pro .
docker run -d --name girl-pro -p 8899:8899 -e ACCESS_TOKEN=你的口令 --restart unless-stopped girl-pro

# docker compose
docker compose up -d --build
```

**GitHub Pages**：fork 后 Settings → Pages → Source 选 `main` 根目录即可（直连模式，无择优）。

## 服务端可调环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `CANDIDATES` | 3 | 并发候选数（越大画质越好、解析越慢） |
| `MIN_KBPS` | 1100 | 最低码率门槛 |
| `PROBE` | 1 | 是否探测元数据（0 关闭，退化为随机直取） |
| `PROBE_CACHE` | 300 | 探测结果缓存秒数 |
| `ACCESS_TOKEN` | 空 | 访问口令（公网防白嫖） |
| `DEBUG` | 0 | 1 开启请求日志 |
